## Sytem requirements:
A windows computer(use a vm if you dont have one)
A system having directx drivers
A cpu with integrated graphics will do.

## Stuff done right now:
 - Tutorial
 - Decent enough sound effects
 - First memory fragment objective
 - escape menu
 - intro screen
 - music in intro screen
 - developer's note when game ends
 - all combat and movement mechanics
 - a debug mode you can enable in Global.gd inside scripts to get secret features!

## What motivated me:
My friend [karnx](https://github.com/karnxx/) told me to make a game with a scary abyss and cool anime fonts with combat features, he was the starting inspiration in this game and i used my creativity along the way to add other stuff.
